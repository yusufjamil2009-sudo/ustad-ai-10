# Premium Mobile Chat Delivery Rebuild

## Scope
Rebuild only the visual response-delivery layer inside the existing NEW USTAD AI Chat Page. Keep the existing request, history, authentication, navigation, model, language, and response-action logic unchanged.

## Build
- Create the luxury glass response wrapper first around the existing real assistant message content and existing action controls.
- Size each final card from the real response length using compact, standard, expanded, and scroll-contained bands, always constrained to the chat viewport.
- Replace the placeholder body-part sketch with two original, cohesive futuristic SVG characters built in-project: a compact thinking specialist and a compact response courier.
- Drive the sequence from the existing request lifecycle: thinking character enters and remains while the real request is active; after the saved assistant message is loaded, it exits and the courier carries that same real response card through presentation, one controlled kick, flight, settle, and exit.
- Keep the chat background and camera fixed, remove traditional typing dots in NEW mode, preserve every existing response action, and make decorative layers non-interactive.
- Provide reduced-motion and visual-failure fallbacks that reveal the real response immediately.

## Validation
- Walk the complete sequence with a real AI response on the existing Chat Page.
- Test 360, 375, 390, 412, and 430px widths for character scale, card bounds, scrolling, controls, and horizontal overflow.
- Confirm desktop behavior, build status, console/runtime errors, one AI call per send, and unchanged existing response actions.
